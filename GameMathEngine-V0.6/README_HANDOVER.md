## 1. 设计哲学（固定项，一条不可改）

- **Y = 阶级机会成本**：成为另一个阶级的成本（欠债/违约/失业/救济金/基尼/凶杀），不是贫困/暴力本身
- **Z = 负面 − 科技**：Z 的符号是 Y 的运动趋势（持续创新指标）
- **Ylimit = (X − 军费) × (基准 + 福利)**：社会承载力；政府债务是负项（债越重承载力越低）
- **G = Y − Ylimit 是唯一输出**：无量纲，只看相对位置；**危机 = G>0（越线），与陡峭无关，幅度=危机大小**
- **kY>1**：Y 比 Ylimit 反应快（上和下都快）
- **危机反馈**：越线 → 伤 X → Y 掉得比 Ylimit 快 → 回落到线下（危机是结果，矛盾累加在危机之前完成）
- **X、Z 有非零下限**（人长手有脑子）
- **X 用一次能源+劳动力，不用 GDP**（GDP 能造假）
- **数据本身即矛盾高低**；全部国家同一套指标；全部数据免费（世界银行批量 + IMF WEO）
- **平均法合成复合指标**（加权项÷项目数，防数值乱飞）
- **逐国仅校准初始 Y/Ylimit 对齐第一个历史事件**，其余全是预测
- **冲击是跳变不是水平**：-2 跳 0.5（未过线）= 1.5 冲击；0 挪 0.3 = 0.3 增量
- **事件 ≠ 骚乱**：大头是无组织无序/集体犯罪（矛盾水平传感器）；有组织大规模（骚乱/罢工/政治危机）是"老百姓多难管"的指针
- **现实 = 游戏最高难度**（D=1.0），低难度只乘系数

## 2. 数学核心（secm_model.py，已冻结参数 best_params.json）

```
X        = 一次能源/人 × 人口/10⁶ + 人口×130/10⁶
Zc       = 平均[ wg·基尼, wu·失业, wm·凶杀, wc·股崩, wcr·信贷崩盘,
                 wnp·坏账率NPL, wge·救济金, wcf·资本外逃(FDI骤降+储备流失) ]
bonus    = max( 平均[ wp·专利增速, we·教育 ], ZtechMin )
Z        = gZ·(Zc − gX·bonus)，去中心(5年滑均)         ← gZ=Z范围增益
Zeff     = sign(Z)·((1+|Z|)^p − 1)，p∈[2,4]            ← 幂次放大保符号
Y        = 累加器: Y_t = Y_{t−1} + ΔlnX·kY·(1+ZI·Zeff) + kZ·Zeff − lam·(Y_{t−1}−Y_base)
           ΔlnX=对数增长(Σ有界，防高速增长国Y失控)；Y_base=a0+a1·Xn^β+μ·ln(1+Xn)(与Ylimit同幂)
Ylimit   = (Xn·(1−军费))^β · (w0 + ww·福利) / (1 + wd·政府债务)
G        = yf·Y − yls·Ylimit   （逐国校准仅 (yf,yls) 对齐第一个历史事件±1年）
G_disp   = S·G   （S=全局显示增益≈0.9-1.0，事件年G中位归一为1）
分带      = <0 安全 | 0~1 承压 | >1 紧张
```

**双画像参数**（都冻结在 code/ 下）：
- `best_params.json`（画像A）：校准 25/25 + 验证 32/33，曲线平稳——数学验证用
- `best_params_spiky.json`（画像B）：验证 33/33，危机尖峰巨大——**游戏用（默认）**

## 3. 游戏如何使用本模块（输入 → 输出）

### 输入（每年，国家指标，全部世界银行/IMF 免费数据）
`Population, energy_pc, murder, health, EduRate, Military, unemployment, mcap_gdp, Gini, Patent, debt_gdp, credit_gdp, npl, gov_exp, fdi_gdp, portfolio, reserves`

### 输出
| 输出 | 含义 | 游戏用法 |
|---|---|---|
| `G_disp`（年） | 危机指数（无量纲） | 分带显示；驱动事件频率 λ(G) |
| `band` | 安全/承压/紧张 | UI 底色/警报级别 |
| `ΔZc`（σ） | 矛盾指标跳变 | **冲击通道**：瞬时事件（未过线也触发） |
| 事件流 | 慢性(水平G) + 冲击(ΔZc) 两类 | 玩家看到的全部内容 |
| 难度 D | 0.4 简单 / 0.7 标准 / 1.0 现实(最高) | 难度选择 |

### 最简调用（已在 code/ 下跑通）
```
cd code
py events_engine.py UK          # 英国事件流, 画像B, 最高难度
py events_engine.py UK 10 A 0.7 # 近10年, 画像A, 标准难度
py g_module.py                  # 看 λ(G) 函数与事件类型严重分数排行表
```

### 确定性
同一国家名 → 同一哈希种子 → 同一局游戏里历史事件流完全可复现。

## 4. 事件引擎（双通道，events_engine.py + g_module.py + event_library.json）

| 通道 | 输入 | 输出 | 公式 |
|---|---|---|---|
| **慢性通道** | 水平 G_disp | 钝刀子事件流（治安/教育/健康/经济/阶级距离/治理变难/无序集体犯罪…） | 频率 `λ(G)=1+D·19·σ((G−0.2)/0.4)`；类型概率 `p_c ∝ w_c·exp(D·θ·s_c·G)`（严重分数 s_c 越高，G 越大越被选中）；严重度 `clip(1+1.2G(0.4+0.6D)+N, lo, hi)` |
| **冲击通道** | 跳变 ΔZc（σ 归一） | 瞬时冲击（突发抗议/恐慌抢购/熔断/挤兑/闪崩） | `I=clip(ΔZc/σ,0,3)`；`λ_shock=1.2·D·I` |

**事件类型严重分数排行表**（g_module.py，G 越大越往严重走）：
缓和 1.0 < 无序集体犯罪 1.5 < 家庭 2.0 < 治安 2.3 < 教育 2.5 < 健康 2.6 < 治理 2.7 < 经济 2.8 < 阶级距离 3.0 < 政治 3.2 < 骚乱 5.0 < 爆发 5.5

**现实频率校准**（英国 25 年对照）：抗议 ≈22 次（现实~30）、真骚乱 ≈1次/5年（现实同）、金融政治爆发 ≈1次/10年+（现实同）、无序集体犯罪常年不断（最大权重）。马来西亚 1997-98 亚洲金融危机：水平未过线，但 Δ=2.0σ 打出熔断/抢购/街头冲突/汇率闪崩 4 条冲击事件 ✓。

**真实锚点**：`uk_events_real.json` 存真实新闻/调研事件（北岩挤兑 2007、英格兰骚乱 2011、刀犯罪 2019、生活成本危机 2022…），可作"史实彩蛋"混入事件流。

## 5. 下游接口规范（游戏侧实现，详见 02_事件引擎与接口.md §4-5）

**危机几率**（爆发事件掷骰，G_disp>1 时）：`p = p0·exp(α·(G_disp−1))`
大骚乱 p0=0.02/α=1.5；挤兑 0.01/2.0；主权违约 0.03/1.2；政权危机 0.005/2.5。

**民众表现（刁民度）**——全部是 G 的单调函数+噪声：
服从度 `1/(1+exp(0.6(G−0.5)))`；劳动热情 `0.8−0.12·max(G,0)`；移民意愿 `0.05+0.10·max(G−0.5,0)`；逃税/非正式经济 `clip(0.05+0.08G,0.05,0.5)`；对政府信任 `0.5−0.10·max(G,0)`；治安配合 `0.8−0.10·max(G,0)`。

**铁律**：下游模块不得有自己的复杂判断，只能消费 G_disp——"G 是唯一输出"的哲学不能泄漏。

## 7. 验证结果与诚实局限（详见 04_验证报告.md）

| | 校准集(6国,1980-2025) | 验证集(14国,2000-2025) |
|---|---|---|
| 事件召回 | **25/25 = 100%** | **32-33/33** |
| 年级精确度 | 26% | 26%（哲学必然：G>0=高矛盾状态，非事件警报器） |
| 误报段 | 0 | 0-1 |

多国曲线对照真实史：英法德阿巴美日新马 9 国体检，法国由债务负项修正、新加坡失控已治（对数累加器）、马来西亚冲击通道点火。**诚实局限**：①年级精确度 26% 是"水平指标"设计的必然；②暴力幅度相关≈0（Y≠暴力强度）；③资本外逃型危机靠冲击通道而非水平通道；④画像B与"首越线对齐"仍有权衡（游戏场景用B无碍）；⑤事件清单是我们定义的，±1年窗口。
