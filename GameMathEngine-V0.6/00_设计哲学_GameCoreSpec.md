# SECM 游戏核心引擎 · 规格 V0.6

> 用途：一个"国家/文明治理"经营建造类游戏的**通用数学核心模块**。
> 本文档只定义**结构与规则**，不写实现代码。学术 SECM 是哲学母体，本引擎是落地。
>
> 核心输出只有一条：**G = Y − Ylimit**（矛盾到红线的相对距离）。

---

## 0. 一句话定位

把"**资源网状分配 → 矛盾(Y)与承载(Ylimit)的动态演化 → 崩溃/更替**"做成可调、可玩、可解释的引擎。玩家在**信息不透明、政策有延迟、民众不听话**的条件下治国，唯一真实的生死线是 **G**。

### 0.1 总原则：No Single-Cause（无单一原因铁律）

> 任何高层概念（腐败、自信、服从、宣传效果、政府能力、情报质量）都**不允许**被写成单一输入变量的直接函数。
>
> 它们必须是"**汇**"——由 **≥3 个上游**共同合成，且其中**至少一个上游是玩家无法直接控制、只能间接影响**的。

**为什么**：一旦允许"砸钱把腐败降到 0"这种单旋钮，网状因果就退化成线性拨款游戏，你的模型就死了。这条铁律是整张网的"护城河"。

## 1. 核心不变量（钉死）

1. **Y = 阶级机会成本**（变成另一个阶级要付的成本），不是泛泛的"社会矛盾"。
2. **Z = 连续创新指标**（专利量、自然指数、有效论文、科技趋势），可正可负；**Z>0 = 科技停滞/倒退（负红利，反而推高 Y）**。
3. **Ylimit = 承载红线**，由 X 供养、含"固定负担项"；**"红线追 Y"（苏联陷阱）**。
4. **G = Y − Ylimit 是唯一有意义的输出**。Y、Ylimit 各自无限增长、绝对值无意义；只有相对距离 G 有意义（**标度不变**）。
5. **两条链不同速**：X→Y 快（当年），X→Z→Y 慢（10~30 年时滞）。**时滞×反馈增益过大 → 自激震荡/爆炸（Hopf 分岔）**。
6. **阻力是涌现的**：不存在"岁月静好"，永久耗散。
7. **前进/后退**：跨不过顶点就退回；革命重置后重爬。

## 2. 资源网络（网状、全耦合）

> 所有资源**互相全有连接**，是**网状**不是**树状**。三层耦合：资源→去向（分配）、去向→资源（反馈）、资源↔资源（二阶连锁）。

### 2.1 资源池（stock）

| 代码 | 中文 | 性质 |
|---|---|---|
| F | 财政 | 通用货币池 |
| P | 人口总量 | 长期 stock，慢 |
| L | 适龄劳动力 | 中速 stock |
| H | 高端人力（研究员/工程师/教师/医生） | 慢 stock，最难造 |
| A | 耕地 | 物理底盘，几乎不可快速增 |
| E | 能源 | 中速 stock |
| M | 矿产/材料 | 中速 stock |
| W | 水 | 中速 stock |
| I | 基建/物流容量 | 慢 stock |
| C | 治理容量（行政能力/政治精力） | 慢 stock，每回合有上限 |

> 粮食、工业品、军备、科研产出是**派生产出（flow）**，不设独立 stock。

### 2.2 四个去向（sink）

- **X** 产能/增长
- **Z** 创新/研发/教育（慢，带时滞）
- **YL** 承载/韧性（Ylimit）
- **Yr** 直接缓解矛盾（福利/医疗/治安）

### 2.3 全耦合矩阵（资源 × 去向）

| 资源 \ 去向 | → X | → Z | → YL | → Yr |
|---|---|---|---|---|
| **F 财政** | 工业/基建投资（+X,+就业） | 教育/科研经费（+Z，慢） | 军费、福利、制度（+YL，军费挤占） | 福利/医疗/治安（−Y 当期） |
| **P 人口** | 劳动力供给（+X 潜力） | 适龄学生（+Z 原料） | 兵源（+防御，抽劳动） | 生育/健康 |
| **L 适龄劳动力** | 生产（+X） | 上学（+Z 未来，当期 X 减） | 参军（+防御，−生产） | 医生/警察（−Y） |
| **H 高端人力** | 工程师下厂（+X 效率） | 科研/教学（+Z，教师→未来 H） | 军工研发（+防御技术） | 医生/公卫（−医疗矛盾） |
| **A 耕地** | 工业/城市用地（+X，−粮食） | 高校/园区（+Z，−粮食） | 军事基地（+防御，−粮食） | 种粮（+粮食，−粮价矛盾） |
| **E 能源** | 工业动力（+X） | 科研/数据中心（+Z） | 军事能源 | 民用供暖/供电（−生活矛盾） |
| **M 矿产** | 工业原料（+X） | 科研材料（+Z） | 军工材料 | 建材/民用品（−生活矛盾） |
| **W 水** | 工业用水（+X） | （少量） | （少量） | 生活/农业用水（−生活矛盾） |
| **I 基建/物流** | 产业物流（+X 效率） | （少量） | 军事物流 | 民生物流（−矛盾） |
| **C 治理容量** | 经济改革（一次只能推几项） | 教育改革 | 制度/反腐/再分配（+YL） | 治安/应急（−Y） |

### 2.4 派生产出（flow）

- **粮食** ← A×Yr；被 P 消耗；A×X 侵占则减产 → 粮价↑。
- **工业品** ← L×X + E×X + M×X；回流 F（税）。
- **军备** ← L×YL + H×YL + E×YL + M×YL；消耗 F/L/H/E/M。
- **科研产出** ← H×Z + F×Z → 提高 Z。

### 2.5 反馈回路（去向 → 资源）

- X → 产 F（税）、E、M、I、粮食（投资 A）。
- Z → 产 H（毕业生）、提高 E/M/A 效率（省资源）。
- YL → 产 C（制度/信任）、降犯罪。
- Yr → 保 P 健康、保 L 就业、压 Y。

### 2.6 二阶连锁（资源 ↔ 资源）

**不做"资源A→资源B"的显式硬编码，靠 sink 层 + flow + 反馈自动织网。**

示例链：A→X（建厂）→ 粮食↓ → 粮价↑ → Y↑ → 需 F 进口 → F 从 Z 抽走 → 教育↓ → H 未来↓ → 10 年后 Z 塌 → G→0 → 红线追来。

## 3. 快慢分层与时滞（防 Hopf 爆炸）

| 类型 | 变量 | 时间尺度 | 规则 |
|---|---|---|---|
| 慢 stock | X、Z、YL、H、I、C | 5~30 年 | 强反馈允许，时滞必须大 |
| 快 signal | Y 各分量（就业/物价/治安/贫富） | 当年 | 只能弱反馈，否则震荡 |

**Hopf 铁律**：`增益 × 时滞 > 阈值` → 自激震荡 → 爆炸。落地两条：快变量只影响显示与弱修正；慢变量投入分多回合结算（时滞）。

**"人才/人口必须慢"**：H 是天然时滞 stock，今天让研究员全搞科研，20 年后才见下一代科学家。

## 4. Y 的构成（矛盾生成：每个牺牲 → 一个增加项）

| Y 分量 | 造成 | 对应资源 |
|---|---|---|
| 贫富差距(Gini) | 财富分配、税制 | F×YL |
| 就业率（反向） | 劳动力分配 | L×X vs L×Z |
| 医疗 | 医生/公卫投入 | H×Yr |
| 治安 | 失业+贫困+信任流失 | L、Yr、YL |
| 粮价/物价 | 耕地/能源分配 | A、E |
| 阶级流动性（核心） | 教育公平+财富集中+信任 | H×Z、F×YL |
| 信任流失 | 制度/治理 | C×YL |

```
ΔY = k_X·ΔX ·(1+PopPressure)  +  k_Z·f(Z)
PopPressure = (人口/耕地) ÷ (人均生产力/承载系数)
```

### 4.1 Z 的构成（科技创新力，四因喂养，非随机摆动）

> Z 是**连续创新指标**（专利量、自然指数、有效论文、科技趋势），由四因**喂养**出来，不是外生摆动：

```
Z = f( 教育, 生活质量, 腐败(负), 上升通道 )
```

- **教育** → 人才供给 → Z↑
- **生活质量** → 研发者安心搞 → Z↑
- **腐败** → 经费被贪、成果灌水 → Z↓（严重时 Z>0 = 科技倒退/负红利）
- **上升通道（阶级流动性）** → 有奔头才创新 → Z↑

**进 Y 前先 log 压缩**：`f(Z) = sign(Z)·ln(1+|Z|)` —— 小 Z 近似线性、大 Z 被压平、保符号。
**小范围**：Z clip 到 [−0.5, +0.5] 左右，防止过大导致 Hopf 震荡。

## 5. Ylimit 的构成（含"军事两难" + "固定负担"= 苏联陷阱）

```
Ylimit = k_Limit × (X − X_军事) × f(Ω)  −  固定负担项
```

- **军事两难（dilemma）**：军事开销从 X 里**扣走**，却**不增加 Ylimit**。
  - 军费小 → X 留存多 → Ylimit 高 → 但军事黑天鹅风险↑（§14）；
  - 军费大 → 防住黑天鹅 → 但 X 被抽 → Ylimit 低。
  - **没有最优解，两头都是坑。**
- **固定负担项**：军备维护、陈旧机器、退休、外债利息——不随 X 涨，但 X 停滞时照扣。
- **苏联陷阱**：苏联把巨额 X 投进军备 → X−军事 被抽干 → Ylimit 塌 → 红线追 Y → 崩。**苏联不是不发展，是发展了全喂枪炮。**
- **Ω 韧性**：储蓄、失业、债务、物流、**金融泡沫比例**合成；泡沫越大，Ylimit 越低（2008 型）。

## 6. 动态递推（每回合）

```
1. 玩家分配资源池 → 四去向（见 §7）
2. 结算 flow + 反馈 → 更新资源池
3. 快链：ΔY += k_X·ΔX·(1+PopPressure)
4. 慢链：Z 按投入·转化率·时滞 分回合积累
5. ΔY += k_Z·Z
6. 更新 Ylimit（含固定负担扣除）
7. G = Y − Ylimit
8. G≥0 → 触发革命/退回（§12）
```

---

### 6.1 突发冲击项（外生黑天鹅 ε）—— 四变量都要预留

> 天灾人祸、黑天鹅会**同时**袭击 X / Y / Z / Ylimit 中的任意组合。每个变量都预留一个外生冲击项 ε（罕见、肥尾、可正可负）：

- **ε_X**：破坏/增益生产力（地震毁厂、大瘟疫、资源发现、技术外溢）
- **ε_Y**：直接推高/压低矛盾（灾难伤亡、流民、恐慌 vs 大捷、盛事凝聚）
- **ε_Z**：中断/加速创新（人才断层、科研中断 vs 战时技术爆发）
- **ε_Ylimit**：摧毁/加固承载（基建损毁、储蓄蒸发 vs 重建、外援）

**与内源黑天鹅的区别**：
- 军事战争（§14.1）、断供 crash（§14.3）是**内源**——由你的军费/依赖度触发；
- 本节 ε 是**外源**——天灾人祸、纯随机，无法用政策避免，只能靠余量硬扛。

**性质**：小概率、大冲击（肥尾）、正负皆可、不设旋钮（玩家只能靠 Ylimit 余量/储备去吸收）。

## 7. 游戏接口

### 7.1 三档难度 = 三层控制权

| 档 | 能直接拨的 | 只能间接影响的 | 定位 |
|---|---|---|---|
| 低 | 大方向（增长/科教/稳定/民生） | 具体拨款/人才/产业 | 上手 |
| 中 | 财政拨款比例、几类人才政策 | 老百姓是否服从（靠基建/补贴/号召） | 标准 |
| 高 | 逐项拨款、逐类人才、宣传、法律 | 更少，但每项都硬核 | 硬核 |

> 备选（高难度内）：开放"直接拨数"（研究员 40/30/30）。

### 7.2 输出信号

- **主血条**：G = Y − Ylimit（唯一核心）。
- **子仪表**：Y 各分量、Z 趋势、Ylimit 趋势、资源池余量。
- **预警**：G 逼近 0 时显示"临界慢化"（恢复变慢）→ 可预测的崩盘前兆。

## 8. 治理层（Governance Layer）—— 玩家政策到实际效果之间的损耗与延迟

> 所有变量都是**涌现的"汇"**，遵循 §0.1。标注：【可控-间接】= 玩家能影响但不能直达；【涌现】= 玩家基本无法直接控制。

### 8.1 腐败（递归）

**上游合成：**

| 上游 | 可控性 |
|---|---|
| 公职人员工资 | 可控-间接（财政拨款） |
| 晋升公平度 | 可控-间接（制度/法律） |
| 法律强度 | 可控-间接 |
| 审查强度 | 可控-间接，但见下"递归坑" |
| 教育度 | 可控-间接（教育投入，慢） |
| 社会信任 | 涌现 |
| 贫富差距 | 涌现（受再分配间接影响） |
| 监督独立性 | 可控-间接，但被腐败反噬 |

**下游影响**：政策损耗率、财政水分、情报保真度、信任。

**递归坑**：审查强度↑ → 短期腐败↓；但审查机构自身腐败↑、言论/创新↓、信任↓ → 长期可能更糟。**监督本身也在被监督，永远有查不清的暗区。**

### 8.2 行政效率（政策延迟）

- **上游**：H（高端人力）、C（治理容量）、教育度、I（基建）、腐败（负）。
- **下游**：政策时滞长短、情报质量。

### 8.3 服从度（民众听不听话）

- **上游**：自信心、信任、宣传、G（离红线越近越不听）。
- **下游**：政策实际生效比例。

### 8.4 宣传（可 backfire）

- **上游**：宣传投入【可控】、教育度、信任、现实兑现度。
- **下游**：自信心、服从度。
- **backfire 规则**：**宣传与现实落差（承诺 vs 兑现）过大 → 信任暴跌**。适度 + 凝聚，过度 − 反噬（倒 U）。

### 8.5 教育度

- **上游**：H×Z（师资/高校）、财政教育拨款、适龄人群。
- **下游**：腐败↓、服从度↑、Z 原料↑、情报质量↑。

### 8.6 失控螺旋（治理层的负反馈环）

> 你做得越差（G→0 或短期超线）→ 民众越不听 → 只能靠间接政策 → 间接政策有延迟、有腐败损耗、可能 backfire → 越难扭转 → 恶性循环。**崩盘前，玩家手里的旋钮一个个变钝。**

## 9. 信息层（Information Layer）—— 玩家看到的是"情报"，不是"数据"

### 9.1 情报三元组

**每个玩家看到的数字 = （数值，颗粒度，保真度）**

- **数值**：声称值（可能有水分）；
- **颗粒度**：精确百分比 / 只有"高·中·低"；
- **保真度**：多可信（硬统计 / 道听途说）。

| 想知道的 | 实际看到的 |
|---|---|
| 真实财政收支 | 有水分，贪了多少查不清 |
| 真实腐败率 | 只有"查出来的腐败率"，暗区看不到 |
| 真实失业率 | 口径不一，可能有政治修饰 |
| 真实不满 | 模糊民调："部分地区怨言增多" |
| 真实科技水平 | 论文/专利灌水，保真度存疑 |

### 9.2 三层漏斗（真实 → 查出来 → 玩家看到）

```
真实世界  →(腐败+统计能力+行政效率)→  查出来的  →(宣传修饰+汇报水分)→  玩家看到的
```

### 9.3 情报质量由治理投入喂养

> **情报保真度 = f(统计/审计/教育投入, 腐败, H 高端人力)**。
>
> 不投人 → 瞎着治理 → 决策烂 → 更穷 → 更瞎（第二个失控螺旋）。

### 9.4 主血条 G 也带保真度（已定：方案 A）

> G 本身也有水分——玩家看不到精确的"G=0.2"，只能看到"红线逼近，可信度：中"。
> 连"离崩溃多远"这件事都不能全信。
> 实现：真实 G → 经（腐败损耗 + 统计能力 + 行政效率 + 宣传修饰）→ 玩家看到的 G 估计值（数值/颗粒度/保真度三元组）。
> 唯一始终可信的只有"已经崩了"（I_reset 触发是硬事实）。

## 10. 信心层（Confidence Layer）—— 把所有模糊项拧成一股绳

### 10.1 国家自信心 Conf

$$Conf = f\big(\text{生活水平相对他国},\ G,\ -Y,\ \text{军力},\ \text{宣传}·\text{民族叙事}\big)$$

**注意**：是**相对值**（过得比别国好），且**G 二次登场**——离红线远、矛盾低、安居乐业也是自信的原料。一个绝对值不富但离红线远的社会，也能有高自信。

### 10.2 纪律性/服从 = 自信心的函数

- 高自信 → 高纪律（民众觉得这国值得守规矩）→ 腐败↓、摩擦↓。
- 但**过度自信 → 自满 → 监督松懈 → 腐败暗生**（倒 U，中间最优）。

### 10.3 外部参照

引擎需要**"他国平均生活水平/军力"背景参照值**（哪怕先不模拟完整地缘）——邻国比你好 → 你自信掉 → 不满滋生 → 服从降 → 可能被外部煽动。

### 10.4 自信心的倒 U + backfire 环

```
Conf 太低 → 民众不认国家、听命崩
Conf 太高 → 自满、监督松、腐败生 → 宣传与现实落差 → backfire → Conf 暴跌
中间适度 → 最优
```

## 11. 四层咬合关系图

```
              ┌─────────────────────────────┐
              │  信息层（情报三元组+暗区）    │ ← 玩家只能透过这层看世界
              └──────────────▲──────────────┘
                             │ 保真度= f(治理投入,腐败,H)
              ┌──────────────┴──────────────┐
              │  信心层（自信/纪律/外部参照） │ ← 纪律性/服从是自信的函数
              └──────────────▲──────────────┘
                             │
              ┌──────────────┴──────────────┐
              │  治理层（腐败递归/行政/服从/宣传）│ ← 政策→实际效果的损耗与延迟
              └──────────────▲──────────────┘
                             │
              ┌──────────────┴──────────────┐
              │  资源网（10池×4去向 全耦合）  │ ← 最底层，X/Z/Y/Ylimit 在此生成
              └─────────────────────────────┘

核心输出（贯穿四层）：G = Y − Ylimit  ← 唯一生死线
```

**要点**：四层不是上下串联的"管线"，是**互相咬合**的——资源网喂养治理层（人才/财政），治理层污染信息层（腐败损耗情报），信息层决定玩家决策，信心层反过来调节服从度→再影响资源网。**没有单向箭头，全是环。**


## 14. 外部层（军事两难 · 军事黑天鹅 · 国际外部源）

> 任何"增益"都有"代价"，且代价**延迟、隐形、越积越深**。这是引擎的通用规律。

### 14.1 军事：两条通道（连续压力 + 离散战争）

**通道A · 连续压力（威慑不足的政治/经济损失）**
- 军费/军力低 → 威慑不足 → 邻国蚕食、贸易打压、地缘胁迫、资源被截 → **持续、渐进**地：
  - 国家信心 Conf↓（§10）
  - 经济持续受损（X 增长受拖累）
  - 主权/外交空间缩水
- 这是"慢刀子"，没有明确爆点，但每回合都在扣。

**通道B · 离散战争（威慑彻底失效 → 军事对抗爆发）**
- 触发：当"对方政治收益 > 对方军事风险"（你的威慑不足以吓退）→ 战争爆发。
- 军费越高 → 对方军事风险越大 → 战争概率越低（但 Ylimit 越低，§5 两难）。
- 战争后果（一次性大损伤）：
  - X↓（生产力被破坏）
  - 所有 Ylimit 增长指标↓
  - Y↑（伤亡、动荡、资源被夺）
  - 可被政策 offset（动员、结盟、紧急管制——但都吃资源、有副作用）
- **胜负 → 信心**：占优 → Conf↑；战败 → Conf↓。

> 两条通道同时存在：平时被"压力"慢慢放血，松懈到阈值 → "战争"突然来一刀大的。

### 14.2 国际外部源（带毒的增益）

| 外部源 | 增益 | 副作用（慢积累） |
|---|---|---|
| 国际投资 | 财政 F↑、X↑ | 经济受外国控制、金融泡沫风险↑ |
| 国际学术交流 | Z↑ | 学术被控制、人才流失、技术卡脖子 |
| 人道主义援助 | 财政 F↑、Yr 缓解 | 国家信心↓、依赖↑ |
| 国际发展贷款 | 财政 F↑ | 债务负担↑（→Ylimit 塌） |

### 14.3 副作用的"慢积累 + 阈值 crash"（不是一刀切）

> 副作用**不是**线性的"用一次扣一点"，而是两段式：
>
> 1. **小规模积累**：每用一回合，依赖度/债务/暴露度**缓慢累积**，表面岁月静好；
> 2. **跨越阈值 → crash**：积累量越过阈值 → **突然崩溃**——断供、抽贷、制裁、资本外逃、债务违约（= 阿根廷 2001、希腊 2009、亚洲金融风暴 1997）。

- 这是**临界转变（critical transition）**：潜伏期 + 突然跳水，与苏联"台阶式崩塌"同构。
- **剂量-时间结构**：借得越多、越久，离阈值越近；某天外部一断，雪崩。
- 与 §14.1 通道B 的战争是同一类"阈值机关"。

## 15. 终局：科技奇点（三支柱门，可选扩展包）

三条件同时满足（缺一不可、单向、不可绕过）：

1. **能量**：核聚变（破能量过峰）
2. **智能**：弱 AI（破认知劳动过峰）
3. **物质**：分子组装生产线（破材料过峰）

- 前奇点：越发展矛盾越大（波浪向上）。
- 奇点处：最大库兹涅茨顶点。
- 后奇点（能翻）：**阶级机会成本 Y→0**（越发展越轻松）→ 无阶级终局。
- 翻不过：革命退回，再来一次同样的考验。

（核心玩法 §1~§13 不需要它也能跑。）
