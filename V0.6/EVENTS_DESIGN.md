# SECM V0.6 游戏接入层 · 危机指数驱动下游模块的接口规范

> 回答核心问题：**SECM 数学核心只负责回答一个问题——"这个社会现在有多少危机？"输出一个无量纲数 G_disp。**
> 其余一切（事件、危机几率、民众表现）都是下游的简单模块：**G_disp 的单调函数 + 噪声**。
> 玩家永远看不到曲线，只看到事件流、危机爆发、民众行为变化。

---

## 1. 分层架构（为什么这样分）

```
┌─────────────────────────────────────────────────────┐
│ 第4层 反馈: 玩家政策 → 改变 X/Z 指标 → 下一年 G 变化  │
├─────────────────────────────────────────────────────┤
│ 第3层 呈现: 事件流 / 危机几率 / 民众表现(刁民度)      │
│          ← 全部是 G_disp 的简单单调函数 + 随机噪声     │
├─────────────────────────────────────────────────────┤
│ 第2层 解释: G_disp 分带: <0安全 / 0~1承压 / >1紧张    │
├─────────────────────────────────────────────────────┤
│ 第1层 核心: SECM —— G = Y − Ylimit (唯一输出)        │
└─────────────────────────────────────────────────────┘
```

**铁律**：下游模块**不得**有自己的复杂模型（不能自己判断"今年该不该骚乱"），只能消费 G_disp。
否则设计哲学"G 是唯一输出、只看相对位置"就泄漏了。复杂只属于核心，下游必须简单。

---

## 2. 危机指数接口（第1-2层输出）

```json
{"country": "UK", "year": 2011, "G_disp": 3.59, "band": "紧张",
 "freq": 23, "sev_base": 4}
```

- `G_disp = S·G`，S 为全局显示增益（画像B下 S≈24，画像A下 S≈0.9）。
- 分带：`<0 安全`、`0~1 承压`、`>1 紧张`。**G_disp>1 即"社会紧张"（作者定义）。**
- 游戏建议用**画像B**（`best_params_spiky.json`）：危机年尖峰巨大（可读性~20×），
  英国验证：2000-2009 安全 → 2009 越线 → 2010-2025 紧张，与真实史完美对应（见 §6）。
  画像A（`best_params.json`）留作数学验证用途（校准+验证双满分）。

## 3. 事件生成模块（已实现：events_engine.py）

**玩家看到的就是它。事件≠骚乱**：大头是治安/教育退化/健康压力/经济紧张/阶级距离/治理变难，
爆发类（骚乱/挤兑/资本外逃）每年最多 1 条、权重极低（约三年一遇）。

| 输入 | 公式 |
|---|---|
| 年事件期望数 λ | `λ = 1.2 (G<0)`；`1.5+5G (0≤G≤1)`；`6.5+12·(G−1)^1.5 (G>1)` |
| 实际条数 | `Poisson(λ)`，上限25；每年同模板去重 |
| 严重度 | `clip(round(1+1.2G+N(0,0.6)), 模板下限, 模板上限)`，1轻微~5爆发 |
| 类别权重 | 按带查表（事件库 `event_library.json`），承压带阶级距离/经济紧张权重最高，安全带只有缓和类+背景 |
| 数值占位 | 每模板自带数值域（如失业率6~14%、高管薪酬60~400倍），保证不出现离谱数字 |
| 确定性 | 国家名哈希做种子 → 同一局游戏里历史可复现 |

真实锚点机制：`uk_events_real.json` 存真实新闻/调研事件（北岩挤兑2007、英格兰骚乱2011、
刀犯罪2019、生活成本危机2022…），游戏可把锚点当"史实彩蛋"混入事件流，其余年份由库生成。

## 3.5 事件分类学：无组织 vs 有组织（作者核心原则）

| 层 | 类别 | 频率 | 烈度 | 由什么驱动 | 反映什么 |
|---|---|---|---|---|---|
| **高频底层** | 无序与集体犯罪（商店盗窃潮/街头斗殴/球迷冲突/飞车抢夺/逃票/破坏公物） | **很高**（G 刚越线就出现，无需尖峰） | 低(1-2) | 矛盾**水平**（G>0 状态） | **真实情况**：老百姓的生活秩序 |
| 中频 | 治安/教育/健康/经济/阶级距离/治理变难（钝刀子退化） | 中（承压带起） | 中(2-4) | 矛盾水平+G 幅度 | 结构性恶化的过程 |
| 低频尖峰 | 大规模抗议/罢工潮 | 约每年1-2次 | 高(3-4) | G 较高 | 民怨的组织化表达 |
| 极低频 | 真骚乱（≈现实1次/5年） | 很低 | 爆发(5) | G 高+触发条件 | **老百姓多难管**的爆发阈值 |
| 极罕见 | 金融/政治爆发（挤兑/违约/政变，≈1次/10年+） | 极低 | 爆发(5) | G 极高 | 体制承载力的崩溃 |

**关键论断（已验证）**：英国 2000-2025 的 G 只是"越线但不尖峰、超得不大"（画像B 紧张带 G_disp 2~5），
现实里无序事件与集体犯罪已经常年不断（英国零售协会 2023：商店盗窃一年约1670万起，创纪录）。
**所以引擎把"无序与集体犯罪"设为最大权重类目（紧张带权重 0.40），无组织高频才是矛盾水平的真实传感器；
有组织大规模（骚乱/罢工/政治危机）只在高 G 时偶发，是"难管程度"的指针。** 两者都由同一个 G_disp 单调导出。

**频率对照现实（英国 2000-2025，引擎输出 vs 真实史）**：

| 类别 | 引擎 | 现实 |
|---|---|---|
| 无序/集体犯罪 | 80 条（紧张年 ~5-6条/年） | 常年不断，商店盗窃 2022-24 创纪录 |
| 大规模抗议 | 22 次 | ~30 次（2003反战百万人/2009 G20/2010学费/2018-19二次公投70万-100万/2020 BLM/2023-24巴勒斯坦每周十万级） |
| 真骚乱 | 2 次 | 5 次（2001三城/2005伯明翰/2011英格兰/2021布里斯托/2024南港） |
| 金融政治爆发 | 0 次 | 1 次（2007 北岩挤兑） |

来源：[Wikipedia: List of protests in the United Kingdom](https://en.wikipedia.org/wiki/List_of_protests_in_the_United_Kingdom)、
[2024 年英国骚乱](https://en.wikipedia.org/?curid=77508970)、[Guardian 2024 骚乱地图](https://interactive.guim.co.uk/uploader/embed/2024/08/uk_far_right_0608/giv-13425JONv6xJ8XC2k/)、
[2023-24 加沙战争抗议](https://en.wikipedia.org/wiki/2023_Israel%E2%80%93Hamas_war_protests_in_the_United_Kingdom)。

## 4. 危机几率模块（规范，待游戏侧实现）

爆发性事件按年/月掷骰，概率是 G_disp 的指数函数（幅度=危机大小的哲学）：

```
p(event) = p0 · exp( α·(G_disp − 1) )   当 G_disp>1;  否则 p=0
```

建议基准（游戏平衡可调）：

| 事件 | p0 (G=1时) | α | 说明 |
|---|---|---|---|
| 大骚乱 | 0.02 | 1.5 | G=4 时约 1.8%/年 |
| 银行挤兑 | 0.01 | 2.0 | 金融型危机才高 |
| 主权违约 | 0.03 | 1.2 | 与政府债务/外汇挂钩可再加乘数 |
| 政权危机 | 0.005 | 2.5 | 极罕见，G 极高才触发 |

> 注意：核心模型自己的判定"危机=G>0 越线"是**状态判定**，不是掷骰。
> 这里的几率模块是游戏层"把危机状态翻译成具体爆发事件"，两者不冲突：先看带，再掷骰。

## 4.5 难度分级（作者原则：现在调的就是最高难度=现实）

**当前全部参数按现实频率/强度标定 = 游戏最高难度（难度系数 D=1.0）。**
低难度不从重调参数实现，而是把现实基线按 D 缩放（`g_module.py` 已内置）：

| 模块 | D=1.0 (最高=现实) | 通用公式 |
|---|---|---|
| 事件频率 | λ(G) | `λ_D(G) = 1 + D·19·σ((G−0.2)/0.4)` |
| 类型偏移 | 按严重分数排行表偏移 | `p_c ∝ w_c·exp(D·θ·s_c·G)` — D<1 时严重类型不轻易出现 |
| 严重度 | 1+1.2G+噪声 | `sev_D = clip(round(1+1.2·G·(0.4+0.6D)+N(0,0.6)), lo, hi)` |
| 骚乱/爆发间隔 | 2年/5年 | `max(2, 2/D)` / `max(5, 5/D)` — 低难度更久一遇 |

建议分档：D=1.0 最高（现实）/ 0.7 标准 / 0.4 简单。**先对齐现实（D=1.0），难度只是乘系数。**

## 5. 民众表现模块（刁民度，规范，待游戏侧实现）

全部是 G_disp 的单调函数（+噪声），供 UI/行为树消费：

| 民众指标 | 公式骨架 | 语义 |
|---|---|---|
| 服从度(配合政策) | `1/(1+exp(0.6·(G−0.5)))` + N(0,0.05) | G=0 时≈0.57，G=3 时≈0.18 |
| 劳动热情 | `0.8 − 0.12·max(G,0)` + N(0,0.05)，下限0.3 | 危机中躺平/摸鱼 |
| 移民意愿 | `0.05 + 0.10·max(G−0.5,0)`，上限0.6 | 机会成本高→用脚投票 |
| 逃税/非正式经济倾向 | `clip(0.05+0.08·G, 0.05, 0.5)` | 老百姓更难管的直接体现 |
| 对政府信任 | `0.5 − 0.10·max(G,0)`，下限0.1 | 与事件流同源 |
| 治安配合(报案/作证) | `0.8 − 0.10·max(G,0)` | 治理成本上升 |

**刁民度的定义**（作者口径）：不是暴力倾向，是"管不动"——配合度下降、非正式经济、躺平、用脚投票。
它与事件库的"治理变难"类目同构：都从 G 单调导出。

## 7. 诚实边界

1. 模板数字是**占位量级**（虚构国家用），史实由锚点承载；游戏国可自行调数值域。
2. 刁民度是 Y（阶级机会成本）的**表现之一**，不是 Y 的定义——哲学不变。
3. 画像B的代价：调参集首越线对齐 19/25（游戏不在乎）；验证集仍 33/33。
4. 事件引擎按年粒度；如需月度，λ 除以12 + 月度掷骰即可。
5. 城市列表目前英/美/西，其余国家用通用占位词——接入哪国就补哪国城市名。
