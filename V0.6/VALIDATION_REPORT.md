## 1. 最终模型（V0.5 结构 + 设计哲学修正）

```
X        = 生产力（GDP 代理），非零下限
Zc       = 复杂度矛盾指数 = Gini + 失业 + 股崩（凶杀/贫困/信任可扩）
bonus    = 科技红利 = 专利增速 + 教育（非零下限：人有脑子）
Z        = γS·Zc − γX·bonus          ← 负面 − 科技（Z 是 Y 的运动趋势）
Zeff     = sign(Z)·((1+|Z|)²−1)      ← 平方放大保符号（左右都放大）
Ω        = 韧性 = 失业 + 股崩（储蓄/债务/LPI 可扩）
Y_base   = a0 + a1·X_norm + b1·Gini + μ·ln(1+X)   ← 水平项（随 X 同速，防漂移）
Y_t      = Y_{t-1} + ΔX·kY·(1+ZI·Zeff)·(1+土地)   ← 累加器（短期振荡）
Ylimit   = X_norm·(1−军费)·kLimit·(1+|Ω|)          ← 承载（军事两难+韧性）
G        = Y − Ylimit   ← 唯一输出，无量纲，只看相对位置
危机      = Y 突破 Ylimit（G>0），与陡峭无关，突破幅度=危机大小
```

**因果方向**：Y 增长 → 触碰 Ylimit → 危机 → 危机先推高 Y、再破坏 X → X 负时 Y 掉得比 Ylimit 快 → 回落线下。

## 3. 关键发现（这轮调参长跑的价值）

1. **V0.5 的 Y_base 水平项是防漂移的关键**：Y_base ∝ X 与 Ylimit ∝ X 同速增长，漂移被结构性地消除；危机来自累加器的短期振荡（Zeff 尖峰）。
2. **"趋势/振荡"分离**：Y_base 承担趋势，ΔX·kY 累加器承担振荡——这是唯一能同时满足"危机命中"和"非危机期安全"的结构。
3. **Z 平方放大保符号**（V0.5 原式）正确解决了"G 虚高"。
4. **Ω 韧性项进 Ylimit** 让承载随失业/股崩动态变化，捕捉金融型危机。

---

## 4. 诚实标注的局限

1. **调参集误报仍偏多**（美阿 76/83 非危机年 G>0）：模型倾向把危机前后数年都标为"越线期"，精确年份定位还可收紧。
2. **4 国数据缺失**（爱尔兰/塞浦路斯/冰岛：WB 失业+股市缺失；加纳：事件单一）。
3. **幅度相关（暴力）为负**：Y=结构性矛盾 ≠ 暴力，作者已确认（矛盾有多种表现）。
4. 凶杀率/贫困率/信任/储蓄/债务/LPI 等 V0.5 指标可继续补入，预计进一步提高精度。
