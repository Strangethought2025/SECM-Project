## 1. 最终模型

```
X        = 一次能源/人 × 人口/10⁶ + 人口×130/10⁶        （能源+劳动力，不用GDP）
Zc       = 平均[ wg·基尼, wu·失业, wm·凶杀, wc·股崩,
                 wcr·信贷崩盘, wnp·坏账率NPL, wge·救济金/政府支出 ]   ← 平均法防乱飞
bonus    = max( 平均[ wp·专利增速, we·教育 ], ZtechMin )  ← 科技红利(非零下限)
Z        = Zc − gX·bonus, 去中心(5年滑均)
Zeff     = sign(Z)·((1+|Z|)^p − 1), p∈[2,4]可调          ← 幂次放大保符号(尖锐端可锐化)
Y        = 累加器: Y_t = Y_{t−1} + ΔlnX·kY·(1+ZI·Zeff) + kZ·Zeff − lam·(Y_{t−1}−Y_base)
             ΔlnX = 对数增长(Σ有界=lnXn, 防高速增长国Y失控: 新加坡/马来西亚教训)
             Y_base = a0 + a1·Xn^β + μ·ln(1+Xn)          ← 与Ylimit同幂, 不甩开承载力
                                                          ← kZ=直接矛盾推力; lam=回拉(不无限爬高)
welfare  = 平均[ 0.5·医疗, 0.5·教育 ]
Ylimit   = (Xn·(1−军费))^β · (w0+ww·welfare) / (1 + wd·政府债务)
                                                          ← 政府债务=承载力负项
G        = yf·Y − yls·Ylimit    ← 唯一输出, 无量纲, 只看相对位置
危机      = G>0(越线), 与陡峭无关, 幅度=危机大小
校准      = 逐国仅(yf,yls)对齐第一个历史事件, 其余全预测
G_disp   = S·G (S≈0.9, 事件年G中位归一为1.0)               ← 游戏显示层
语义      = G_disp<0 安全 | 0~1 承压 | >1 社会紧张
```

## 4.5 多国曲线对照真实史（样本扩大后逐国体检）

| 国家 | 模型(画像A) | 现实 | 判定 |
|---|---|---|---|
| 英国 | 2000-2025 承压（贴线略上） | 紧缩十年+骚乱，长期高矛盾国 | ✓（作者已确认英国恒紧张正确） |
| 法国 | 承压（债务项拉低Ylimit救回） | 黄背心/2023骚乱 | ✓（此前画像B误判"全欧最安全"已修正） |
| 德国 | 承压（温和过线） | 总体温和 | ✓~ |
| 日本 | 承压（Gd -3~+1 波动） | 停滞但有序 | ✓~ |
| 阿根廷 | 1980-92承压→1993-2025紧张 | 常年危机国 | ✓（1989/2018-19峰偏弱） |
| 巴西 | 承压→紧张单调升 | 慢性高紧张 | ✓（危机峰不突出） |
| 美国 | 承压→1998起紧张(2020暂落) | 撕裂时代 | ✓（1992/2001/2008峰不明显） |
| 新加坡 | 承压→1990起紧张(+1.6) | 高度有序 | ~（失控已修: +15→+1.6；但仍偏紧张） |
| 马来西亚 | 1984起紧张 | 中等 | ~（1997-98亚洲金融危机未突出） |

**本轮两个真 bug 修复**：
1. **Y 累加器失控**（新加坡 Y 从 0.9 涨到 4.6、Gd +15 假性永久巨灾）：改为**对数增长累积** ΔlnX（Σ有界=lnXn），并让 Y_base 与 Ylimit 同幂 Xn^β——高速增长国不再甩开承载力。
2. **法国型高福利国误判安全**：政府债务入 Ylimit 负项后，法国（债务 60%→115%）Ylimit 被拉低，从"全欧最安全"修正为承压。

**已知残留问题**（诚实标注）：画像B（尖峰版）在日志累加器下校准对齐从 23/25 掉到 13/25——"尖峰可读性"与"首越线对齐"的结构权衡依旧存在；阿根廷 1989、马来西亚 1997-98 的危机峰仍不突出（私人部门资本外逃型危机在现有指标中信号弱）。

## 5. 结构权衡（本轮核心发现，诚实呈现）

以"可读性"（事件年 G 相对非事件年的幅度比）为目标的搜索揭示：

| 画像 | 校准 | 验证 | 可读性 | 含义 |
|---|---|---|---|---|
| **A（已选定）** | 25/25 | 33/33 | ~1.1 | 越线检测靠**时间对齐**：事件年与平静年 G 幅度接近，图表需看"越线时机"而非幅度 |
| **B（备选，存 best_params_spiky.json）** | 19/25 | 33/33 | ~20 | 危机尖峰巨大、图表一眼可见；但尖峰导致**提前越线**，6 个校准事件的首越线对齐失败 |

**原因**：逐国校准要求"第一次越线±1年=第一个历史事件"。尖峰越大（p 高/kZ 大），越线越早，对齐越难。满分校准与大幅度可读性在当前结构下互相拉扯。若游戏想要"一眼可见的紧张尖峰"，可接受画像 B（验证集仍 33/33，只是调参集 6 事件对齐失败）；若坚持校准满分，则看 G_disp 的越线时机。

## 6. 设计哲学核对（一条未动）

- [x] Y=阶级机会成本（欠债/违约/失业/救济金/基尼/凶杀），不是贫困/暴力本身
- [x] Z=负面−科技，是 Y 的运动趋势（sign 决定方向）
- [x] Ylimit=(X−军费)×(基准+福利)，政府债务为负项
- [x] G=Y−Ylimit 唯一输出，无量纲，只看相对位置
- [x] 危机=越线(G>0)，与陡峭无关，幅度=危机大小
- [x] kY>1；危机反馈(越线→伤X→Y掉更快→回落线下)
- [x] X、Z 非零下限；平均法合成；逐国仅 YFirst 对齐；全部国家同一套指标；全部数据免费

## 7. 诚实局限

1. 年级精确度 27%：G>0=高矛盾状态（哲学使然），非事件警报器。
2. 事件清单由我们定义（主权违约/IMF救助/政权危机，±1 年窗口），100% 只对该清单成立。
3. 冰岛股市/军费 WB 缺失（已替代）；Gini 多数国家仅十几年（填充处理）。
4. 暴力幅度相关未获支持（r≈0）；若游戏需暴力维度应单独建模。
5. 参数随机搜索选定（22 全局参数 + 逐国 yf/yls），未做 V-Dem/UCDP 交叉验证（下一步）。
6. 画像 B 的校准折损是"首越线对齐"机制与尖峰可读性的固有矛盾，已如实呈现。
